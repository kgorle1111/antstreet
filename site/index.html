3 Investor Row

Enter the investor. That’s you.

You bring an idea and a budget. The boss drafts pytest checks, and you approve them before any code exists. Workers cannot edit them.

Your approval is signed with a key no worker can read.

4 Construction Lane

The bull hires the ants.

The boss, an LLM, runs the crew: headless Claude Code agents that build in small, budget-capped slices. Money is released in rounds against passing checks. Stalled workers are fired.

5 The Gate

Not the agent. The gate decides.

The gate runs the checks in a sandbox: macOS seatbelt, Linux bwrap (required in CI on Linux). A pass needs pytest to exit 0 and a signed proof that every test really ran.

A replay of a test-suite run with a fake model, so the check is a toy one. The output strings are the real ones.

6 Ledger Street

Every decision, chained.

Each line of the ledger carries the hash of the one before it. Edit a line and the chain breaks. Your approvals are signed.

At the end you get a board report: which checks passed, whether they ran sandboxed, and what it cost (the CLI’s estimate, not a bill).

Fund your first idea.

Honest limits

Is a team of agents better than one?

Not on small tasks, by our own blinded benchmark: 64 vs 62 of 105, not shown, at about 2.4× the cost. AntStreet is for verification and control.

Can an agent fake a pass?

A determined adversary can forge one. That risk is accepted and written down (threat row T12). Do not run ideas or code from sources you do not trust.

How strong is the sandbox?

Partial. macOS uses a deny-by-default profile; Linux uses bwrap, required in CI. With no working sandbox tool, checks run with your full access: antstreet doctor warns, and BOSS_GATE_SANDBOX=require refuses. Container isolation is not built.

Do the checks catch everything?

Checks catch only what they test, and the boss can write a weak one. You reading them before any code exists is the control.

What does it run on?

Python with pytest only; one machine, one user; macOS or Linux. Early and pre-release.

What does a run cost?

You set the budget, and money is released in rounds against passing checks. The boss’s own drafting call is charged on top (about $0.03 to $0.10 on Haiku). Spend figures are the CLI’s estimates, not a bill.
